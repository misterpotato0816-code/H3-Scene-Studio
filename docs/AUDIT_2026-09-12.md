# H3 Scene Studio — 全体監査と改善（2026-09-12）

対象は `4456cc39825eb55054365d548e04be488a970a7c` を基点とするH3アプリです。ソース構成、HTTP API、保存・継続・再生成、AI監督、発話プロンプト、UI、モデル管理、公開対象ファイルを確認しました。外部ノードとモデルの実行環境は取得・更新していません。以下はソース監査とCPUテストの結果であり、「重大バグが一切ない」「日本語音声が完成した」という判定ではありません。

## 修正した主な問題

| 重要度 | 問題と影響 | 対応 |
|---|---|---|
| 高 | 静的ファイルの検証が文字列の前方一致で、同じ接頭辞の隣接ディレクトリまで許可し得る | 実パスの親子関係で検証。シンボリックリンクも確認 |
| 高 | 単発プロジェクトIDと出力prefixの検証不足 | ID形式・保存ルートを検証。Windows/Unixの絶対パス、親移動、ドライブ指定を拒否 |
| 高 | 外部WebページからローカルAPIを操作できる余地 | Host/Origin/Fetch Metadataを確認。変更APIをJSON、画像のみmultipartに限定。既存heartbeat・モデル解放もJSON化 |
| 高 | 内容保存・構成保存で承認済みクリップのロックが落ちる | サーバーのロック・生成状態を維持。承認済みクリップへ影響する変更を拒否 |
| 高 | 構成保存に台詞編集を含めると、古い動画・コンパイル済み台詞を保持する | 内容変更も再生成が必要な境界として扱い、古い生成プロンプトを無効化 |
| 高 | ローカルAI監督の実行・モデル解放が動画のGPU処理と競合し得る | 共通ジョブ枠内で実行・解放。busy時の未await coroutineも閉じる |
| 高 | 単発・再試行などで指定台詞との最終照合を通らない | 動画の共通投入経路で発話ガード。欠落・追加・改変・壊れたタグ・未許可の第二話者を停止 |
| 中 | 環境音の置換が、台詞内の「人の声」「太鼓」なども改変する | `<d>[Japanese]…</d>` 内を保護し、環境音だけ変換 |
| 中 | 単発の台詞空欄に「台詞を創作してよい」と指示していた | 空欄を無言へ統一。継続とキャッシュ再生成も対応する台詞条件を保持 |
| 中 | AI回答の例示JSONが最終回答より優先される | 最後の解析可能なトップレベルJSONを採用。コードフェンス内の例も先勝ちにしない |
| 中 | APIキー送信先の検証がURL内の部分文字列だけ | HTTPS・正規ホスト・許可パスの完全検証とリダイレクト拒否 |
| 中 | 音声画面に動画生成の固定ボタン、ストーリー停止が単発停止を呼ぶ | モードごとの操作を修正。重複した生成ボタン・互換性表示・フォルダ操作を整理 |
| 低 | 設定ファイルなしで起動したインスタンス間に既定値の変更が伝播 | 既定設定をdeep copy |

ローカルAPIは `http://127.0.0.1:8790/` または同じホスト名のlocalhostから利用します。LAN公開・別Originからの埋め込みは対象外です。APIスクリプトでPOSTする場合は `Content-Type: application/json` を指定してください。

## 日本語音声・ディレクション

台詞と演技指示を分離し、話し方を「自然な会話／柔らかく／落ち着いて／明るく」から選べるようにしました。これはH3への演技指示で、音素やピッチを直接固定する機能ではありません。指定外の文字列がプロンプトに混入する問題を止めても、モデル出力での読み間違いや余分な発声を完全に防げるわけではありません。

監督案では台詞を直接編集できます。ロックした台詞は編集不可です。単発のショット開始・終了時刻を編集し、0秒開始、時刻逆転・重複、尺超過を生成前に検証します。タイムラインの英語描写もコンパイルに利用します。演出プリセットは「ワンカット」「会話の余白」「静かな映画」。台詞量の既存推定と実際に投入する台詞一覧を同じ確認欄へ表示します。

VOICEVOX試聴は `127.0.0.1:50021` のみを利用し、外部サービスへ台詞を送信しません。試聴WAVはファイル保存せずブラウザへ返します。エンジンが未導入でも通常のH3は利用できます。**VOICEVOXの声・アクセント調整値はH3生成へ自動適用されません。** H3音声テストへ渡せるのは台詞の文字列です。

## 実機で残っている確認

同じ人物・同じseedで変更前後を比較してください。次の台詞は確認用の例であり、合格済みの音声ではありません。

| ケース | 台詞例・操作 | 確認点 |
|---|---|---|
| 自然な語尾 | 「あ、見て。きれいだね。」 | 語尾の不自然な上昇・急ぎ・途切れ |
| 疑問 | 「あれ、もう帰るの？」 | 問いかけの抑揚と相手への視線 |
| 間とためらい | 「うーん、どうしようかな。」 | 息継ぎ、長音、文末の余裕 |
| 台詞保護 | 「あの人の声、聞こえた？」 | 台詞の文字が環境音の指示に置換されない |
| 無言・続き | 台詞空欄で生成し、「続きを作る」 | 指示の読み上げや前の台詞の繰り返しがない |
| 連結 | 10秒×3クリップ | 声質・音量・継ぎ目・口パク |

過去の135.6秒・217.61秒などの計測値は、この更新後の速度や品質の保証ではありません。共通VLM指示を変更しているため、生成結果のバイト一致も主張しません。今回の修正を実機で生成・試聴した後に、音声品質の完了判定を行います。
