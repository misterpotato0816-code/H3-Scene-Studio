## 修正

- `app/h3app/director_lexicon.py`
  - 台詞あり: 従来のリップシンク指示
  - 台詞なし: 声質・話し方の指定を出さず、全被写体を無言として扱う
  - 新規クリップ: 穏やかに閉口した状態を全編維持
  - 継続クリップ: 前クリップの終端ポーズを新クリップの第1フレームへ引き継ぎ、
    その後は自然に閉口して無言を維持
  - 無言のVoice Master参照: `<Audio 1>` の接続ラベルだけを維持し、声質・発話出力を
    要求しないことを明記
  - サウンドスケープにも、台詞や発話様の発声を生成しない制約を追加
- `app/tests/test_audit.py`
  - 無言Directorプロンプトに `spoken dialogue` / `<d>` が入らない回帰テスト
  - 台詞あり、空白だけの台詞、2人の無言、継続クリップ、無言Voice Masterを個別に検証
  - 無言時に `Voice:` と声質指定が漏れないことを検証
  - Windowsの非管理者環境でも静的パス脱出テストを実行できるjunction版fixture

## 第三者レビュー

Codex with ChatGPT の読み取り専用レビューを、OAuthと短時間のペアリングを必須にした
一時接続で実施した。未認証のMCP要求はHTTP 401となることを確認した。`.c2cignore` で
個人設定、認証情報、参照画像、生成動画、音声、モデル、ローカル実行データを明示的に
除外し、レビュー対象をソース、テスト、サニタイズ済みレポートに限定した。

初回レビューで、2人シーンでは被写体2の無言制約が不足すること、継続クリップで
「全編閉口」と前フレームのポーズ継承が衝突し得ること、台詞なしでも声質指定が残ることを
指摘された。再レビューでは継続元と継続先の姿勢関係、および無言Voice Masterの説明経路を
追加で修正した。台詞ありの既存挙動を変えない回帰テストも追加した。

第三者が独立に確認できた範囲はコード、差分、テスト契約である。`.c2cignore` から除外した
参照画像、個人設定、生成メディアについての結果は、この実機確認でCodexが測定・観察した
証拠であり、第三者レビューが再閲覧または再測定した結果ではない。

修正後の第2回レビューは `DONE` / success criteria PASS。継続元の終端姿勢から継続先の
第1フレームへの関係、無言Voice Master、台詞あり・無言・空白台詞・2人・junctionの各契約、
意図しない差分がないことまで確認され、追加修正は不要と判定された。
