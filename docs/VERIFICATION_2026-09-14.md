# 実機検証の要約（2026-09-13〜14、初期公開版）

検証機: Windows 11、RTX 4070 Ti 12 GB（動画生成）+ RTX 3060 12 GB（text encoder / VAE）、ComfyUI 0.34.5。
他の環境での再現性は未確認です。詳細な作業記録は非公開の開発リポジトリに保存しています。

## ストーリーのつなぎ目（「自然につなぐ」）

同一人物・同一ショットの 2 クリップ（LONG、各 124 フレーム / 5.17 s）を生成し、同じ素材を「カット」と「自然につなぐ」で結合して比較。

| | カット | 自然につなぐ |
|---|---|---|
| 境界の平均輝度 | 114.1 → 104.8（Δ-9.1） | 114.1 → 113.4（Δ-0.7）、約 2.2 s かけて元の明るさへ減衰 |
| 境界のフレーム差分 | 11.1、直後 0.61 / 0.22 / 0.19（ほぼ静止） | 7.3、直後 0.47 / 1.49 / 1.12（動きが続く） |
| 次クリップ先頭の除去 | 0 | 7 フレーム（0.29 s）、音声も同じ量だけトリム |
| 台詞（Whisper medium） | 2 文とも一致 | 2 文とも一致（欠落・重複なし） |

生成結果のばらつき: 別の試行では次クリップが無地背景の別ショットになった。この場合は「要確認」と表示され、色補正は行われない（該当クリップの再生成を推奨）。

## 高画質化（576×1024 / 24 fps / 248 フレーム / 音声付き → 1080×1920）

| 方式 | 処理時間 | ピーク VRAM | 備考 |
|---|---|---|---|
| 標準拡大（Lanczos, FFmpeg） | 2.1 s | 0 | 追加モデル不要 |
| RealESRGAN x4 → Lanczos 縮小 | 782 s | 7,138 MiB | ComfyUI 標準のタイル処理ノード |
| SeedVR2 7B fp16 | 3,188 s | 4,991 MiB | 全ブロック CPU オフロード + 入出力層オフロード + VAE 512 px タイル |

いずれも出力の fps・フレーム数・尺・比率・音声の有無を元動画と照合。

## 起動・終了

- `RUN_H3.bat` / `STOP_H3.bat`（画面の「H3を終了」も同じ処理）で起動・終了を複数サイクル。終了時にモデル解放 → H3 が起動した ComfyUI の終了 → 設定が有効なら**このセッションが接続した** LM Studio の終了 → ポート（8790 / 8411 / 1234）解放を確認。
- 別 PC の LM Studio や、記録と一致しないプロセスは終了しない（単体テスト）。

## LLM 接続先

- 既定の接続先は LM Studio（`connection.provider = lmstudio`）、Gemma フォールバックは OFF。ComfyUI-llama-cpp を導入していない構成で、単発生成・続き・ストーリーの監督案と人物解析が設定済みプロバイダーで動くことを単体テスト（モック）で確認。未設定のまま生成すると「設定 > LLM接続」への案内で停止し、他のプロバイダーへは送らない。ComfyUI-llama-cpp 無しでの実動画生成は未確認。
- 実接続を確認: OpenCode Go、LM Studio（モデル一覧・接続テスト・画像入力・監督案生成）。
- モックテストのみ: OpenAI / Anthropic / Google Gemini / OpenRouter / 外部 OpenAI 互換、Ollama / llama.cpp server / vLLM / LocalAI。
